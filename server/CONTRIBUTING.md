# Contributing to SkillBridge

Thank you for your interest in contributing to SkillBridge! This document provides guidelines for contributing.

## 🎯 How to Contribute

### 1. Fork & Clone
```bash
git clone https://github.com/yourusername/Digital-Apprenticeship-App.git
cd Digital-Apprenticeship-App
git checkout -b feature/your-feature
```

### 2. Make Changes
- Work on your feature branch
- Keep changes focused and atomic
- Follow code style guidelines

### 3. Commit & Push
```bash
git add .
git commit -m "feat: Add new feature description"
git push origin feature/your-feature
```

### 4. Create Pull Request
- Open PR with clear description
- Link related issues
- Request review from maintainers

## 🔍 Code Style

### JavaScript
- Use ES6+ syntax
- Add comments for complex logic
- Follow naming conventions
- Keep functions small and focused

### React
- Functional components preferred
- Use hooks (useState, useEffect, useContext)
- PropTypes or TypeScript for type checking
- Keep components under 200 lines

### CSS
- Use Tailwind utility classes
- Follow color palette
- Mobile-first approach
- Test responsive design

## 🧪 Testing

- Write tests for new features
- Test on mobile devices
- Check browser compatibility
- Verify accessibility (a11y)

## 📝 Commit Messages

```
feat: Add new feature
fix: Fix bug
docs: Update documentation
style: Format code
refactor: Reorganize code
test: Add tests
```

## 🚀 PR Checklist

- [ ] Code follows style guide
- [ ] Comments added for complex logic
- [ ] Tests written and passing
- [ ] Documentation updated
- [ ] No breaking changes
- [ ] Responsive design tested
- [ ] No console errors/warnings

## ❓ Questions?

- Check documentation
- Open an issue
- Ask in discussions
